#   silentcipher MUST be installed from this file (not a separate
#   `pip install silentcipher` or an inline-list cog.yaml). silentcipher's
#   own requirements.txt (github.com/sony/silentcipher) declares
#     torch>=1.8.0,<=2.0.0   numpy>=1.25.2   scipy>=1.11.4
#   If pip installs silentcipher in a separate transaction, our numpy/scipy
#   pins here no longer constrain it — pip is then free to pull scipy 1.13+
#   (compiled against the NumPy 2.x C-API) on top of the 1.x numpy that
#   torch 2.0.0 + numba 0.59.x require. At `import scipy` time the C extension
#   can't bind to the installed 1.x numpy ABI and raises
#     RuntimeError: Numpy is not available
#   before predict.py runs the encoder. Keeping silentcipher + every dep in
#   THIS file makes pip's resolver see all constraints at once, so scipy
#   stays at 1.12.0 (last wheel built against the NumPy 1.x ABI and
#   compatible with torch 2.0.0 / numba 0.59.x here).
