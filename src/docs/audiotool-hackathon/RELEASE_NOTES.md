# Audiotool Bridge — "Let's Build" submission

BASE Station joins your Audiotool Nexus session as a live peer. It writes devices, notes, automation, patterns, samples and cables in real time, and exports every master with a watermark, an ownership score, a C2PA seal, a Base anchor and an Audius release.

**Try it:** https://base-station.base44.app/audiotool
**Code map:** `src/docs/audiotool-hackathon/CODE_INDEX.md`
**Pitch and limits:** `src/docs/audiotool-hackathon/README.md`

## Highlights
- Live two-way Nexus peer client
- Beat & Pattern, Harmony & Arrangement and Vocal Lab workspaces
- Songstarter hub and 60s Pre-Starter
- MIDI Co-Producer with undo-aware AI telemetry
- Live human/AI Contribution Meter
- Foundry DSP device mapping with cable mirroring
- Protect & Register pipeline, then Audius distribution

## Honest limits
- Cadence beds use CC-BY-NC weights, so they're for drafting only
- Audiotool runs in a pop-out window because it can't be iframed
- Audiotool's API doesn't expose cover art, templates or VST hosting
